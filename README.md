# SIH 26126 — Vision-Based Autonomous Navigation for UGV

Autonomous navigation of an unmanned ground vehicle in outdoor and GPS-denied environments using vision-based perception, visual localization, traversability mapping, path planning and motion control.

## Problem Statement

Vision Based Autonomous Navigation for Unmanned Ground Vehicle for Outdoor Environment.

## Core Pipeline

Camera → Perception → Localization → Traversability Map → Path Planning → Motion Control → UGV

## Technology Stack

- ROS 2

- Python / C++
